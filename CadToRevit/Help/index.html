Getting Started

Open a Revit project, import or refresh the DWG, review layer mappings, and generate the required model elements before using room recognition, equipment layout, or delivery route planning.

  1. Import the DWG and confirm the detected unit and level.
  2. Run Layer Analyze and assign Category and Family Type where required.
  3. Generate or rebuild walls, columns, doors, and floors.
  4. Use Room & Lift to recognize or define the required spaces.

Model Generation

The CAD Import Wizard converts mapped DWG layers into Revit elements.

  • Refresh Dwg reloads the same source drawing while preserving existing layer mappings.
  • Generate creates elements for a mapped layer.
  • Rebuild updates generated elements after DWG or parameter changes.
  • Detach Elements removes the CAD binding while keeping the generated Revit elements.

Room & Lift

Recognize rooms and lifts from the generated model, or create them manually when automatic recognition is incomplete.

  • Use Auto-Detect after the model has been generated.
  • Use Create Room or Create Lift for manual definition.
  • Edit names and display information from the Room Management pane.

Restricted Area

Create no-go areas that are passed to the delivery route API. Restricted areas can be located, renamed, deleted, or cleared from the left pane.

Layout Plan

Create AHU or PAU layout plans for New Building Design or RMAA / Replacement workflows.

  1. Select the planning context and equipment type.
  2. Select a target room and flow rate.
  3. Run Size Evaluation and select equipment.
  4. Review Valid or Oversized results returned by the room-fit API.
  5. Confirm equipment, configure connectivity, then Save or Save & Submit.

Delivery Route

  1. Select a Start Lift and Target Room.
  2. Ensure the target room has committed equipment from Layout Plan.
  3. Click Generate Delivery Route and review the returned route and sub-modules.
  4. Save the route, open Detail, compare valid routes, or export the report.

Export IFC

Exports the prepared model for downstream path analysis and deliverables. Temporary room visualizations and designated helper objects are cleaned before export.

Export Drawing

Creates a five-page A2 PDF containing Top, Front, Back, Left, and Right views. The preview is displayed inside the plugin using WebView2.

Settings

Review global model generation, recognition, and display settings before processing a new project.

Family Library

Review the available AHU family catalog, equipment dimensions, flow rates, and maintenance information.

Troubleshooting

Layer shown as Unknown

Select the correct Category and Family Type, then Generate or Rebuild the layer.

Route API is not ready

Open Route API from the ribbon, review its status and log, then run Health Check or Restart API.

Placement point is outside the room

Confirm the red placement-point marker is visually inside the selected room and review the room boundary.

Equipment is Oversized

Review the returned reason. RMAA / Replacement layouts cannot be confirmed or saved when the equipment does not fit.

Door generation failed

Check the selected door family, wall thickness, and Revit failure message. Some families may fail at a specific host-wall thickness.

Help page does not load

Use Open in Browser in the Help Center toolbar and verify that the Help folder is installed beside CadToRevit.dll.
